## 5. ML Architecture & Pipeline Inventory

| Component | Design / Specification | Implementation Reality in Codebase |
| :--- | :--- | :--- |
| **Pipeline Paradigm** | Described in early docs as "MobileNetV3 anatomical router $\to$ specialist models" | **Calibrated Tri-Backbone Vision Ensemble:** DenseNet-201 + ConvNeXt-Small + EfficientNet-V2-M, with standalone EfficientNet-B4 for primary monolithic screening and Grad-CAM. |
| **Target Conditions** | Early docs reference "7 visible eye conditions" | **5 Primary Fundus Classes:** `Normal`, `Diabetic Retinopathy`, `Glaucoma`, `Cataract`, `Age-Related Macular Degeneration`. Knowledge base details 6 conditions. |
| **Edge Inference** | Client-side zero-cloud screening | `frontend/public/models/edge_model.onnx` executed via ONNX Runtime Web WASM SIMD in `frontend/src/edgeInference.js`. |
| **Input Resolution** | Multi-resolution input pipeline | $384\times384\times3$ for EfficientNet-B4/V2-M and ConvNeXt-Small; $224\times224\times3$ for edge model. |
| **Preprocessing** | Standardized retinal normalization | Ben Graham circle cropping, luminance-isolated LAB-CLAHE, anti-aliased circular aperture masking, and ImageNet normalization (`mean=[0.485, 0.456, 0.406]`, `std=[0.229, 0.224, 0.225]`). |
| **Calibration** | Post-hoc probability calibration | Platt temperature scaling ($T \in [1.06, 1.34]$) + Adaptive Weight Conformal Risk Control (AW-CRC) bounding error rate at $\alpha=0.05$. |
| **Explainability** | Visual feature localization | Penultimate layer Grad-CAM saliency extraction + spatial quadrant anatomical descriptions. |
| **Clinical Guardrails** | Multi-layer screening defense | Optical chromophore ratio validation (`fundus_validator.py`), Image Quality Assessment (`iqa.py`), and rule-based symptom discordance cross-checking (`analyze_symptoms`). |
