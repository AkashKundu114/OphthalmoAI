# OphthalmoAI — Eye Disease Screening

A full-stack ophthalmology screening app for **7 visible eye conditions**, using a
MobileNetV3 router, specialist EfficientNet-B4 models, Grad-CAM heatmaps, symptom
cross-checks, and a chat helper for follow-up eye-health questions.

> ⚕ **Medical Disclaimer:** OphthalmoAI is a research and educational screening tool. It
> is **not a substitute** for professional medical diagnosis, advice, or treatment.
> Always consult a qualified ophthalmologist.

---

## What changed in this working session

This package includes the original OphthalmoAI codebase plus four completed pieces of
work, all functionally verified (not just written) — see `WIRING.md` for the full
breakdown:

1. **Real async DB access for auth** — `backend/db_async.py`, `backend/auth.py` now use
   a genuine `AsyncSession` instead of blocking the event loop.
2. **Three endpoints that were documented but never implemented** —
   `POST /scans/{id}/override`, `GET /admin/audit-logs`, `POST /admin/model-registry/activate`
   — in `backend/routes_admin.py`, covered by 14 new tests.
3. **Alembic migration scaffolding** — `alembic/`, autogenerated against the real schema,
   verified `upgrade`/`downgrade`/`upgrade` round-trips cleanly.
4. **CI updated** to install the new async DB dependencies and validate migrations.

Along the way, three genuine pre-existing bugs were found (by actually running the app)
and fixed:
- A wrong import name that would `ImportError` on any clean checkout.
- A `structlog`/`PrintLoggerFactory` incompatibility that crashed on the first log call.
- **A `MutableHeaders.pop()` call in the security-headers middleware that would have
  crashed every single HTTP response in production.**

The chatbot's `GEMINI_MODEL` already defaulted to `gemini-2.0-flash` — Google's
free-tier Flash model — before this session; that default is unchanged, just documented
more explicitly in `backend/main.py`.

|-----------|-----------------|---------|

| **Uveitis** | Anterior Segment | 🔴 Urgent |

## Quick Start — Docker

```bash
git clone <this-repo>
cd OphthalmoAI
cp env.example .env           # fill in GEMINI_API_KEY or OLLAMA_URL
docker compose up --build -d
docker compose exec backend alembic upgrade head   # added this session
```

Open **http://localhost:8080**. Model weights are not included — mount `models/` or
rebuild after training (see below).

## Local Development

```bash
python -m venv venv && source venv/bin/activate
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
pip install -r backend/requirements.txt

# Dataset in dataset/<Group>/<Condition>/ per HIERARCHY in backend/main.py
python scripts/verify_dataset.py
python scripts/train_router.py
python scripts/train_anterior.py
python scripts/train_surface.py
python scripts/calibrate_models.py
python scripts/evaluate_models.py

alembic upgrade head          # added this session
python backend/main.py        # http://localhost:8000, Swagger at /docs

cd frontend && npm install && npm run dev   # http://localhost:5173
```

## API Reference

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| `GET` | `/health` / `/ready` | ❌ | Liveness / readiness |
| `GET` | `/conditions` | ❌ | All 7 condition metadata |
| `POST` | `/predict` | ❌ | Eye scan inference (rate-limited) |
| `POST` | `/chat` | ❌ | AI Doctor chat (Gemini Flash free tier / Ollama) |
| `POST` | `/auth/register` / `/auth/token` | ❌ | Account creation / login |
| `POST` | `/auth/logout` / `GET /auth/me` | 🔒 | |
| `POST` | `/scans/{id}/override`* | 🔒 clinician/admin | Record a second opinion |
| `GET` | `/admin/audit-logs`* | 🔒 admin | Query the audit trail |
| `POST` | `/admin/model-registry/activate`* | 🔒 admin | Promote a model version |

`*` = added this session. Full schema: `docs/technical/BACKEND_SCHEMA.md`.
