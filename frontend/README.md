# OphthalmoAI Frontend

React 19 single-page application built with Vite 7 and Tailwind CSS for retinal disease screening.

## Features
- **Dual Audience Persona Modes**: Toggle between **Public View** (patient-centric, simplified guidance) and **Academic / Clinical View** (deep statistical metrics, tensor distributions, 1-click BibTeX citation).
- **Interactive Crop & Quality Check**: Guided 1:1 image positioning and instantaneous pre-inference Image Quality Assessment.
- **Side-by-Side Saliency Visualisation**: Color fundus scan displayed alongside high-resolution Grad-CAM heatmaps.
- **Modern Clinical PDF Export**: Professional vector clinical reports with embedded scans, triage badges, ICD-10/SNOMED-CT codes, and clinician attestation block.
- **AI Clinical Chat**: Interactive consultation with Google Gemini 2.0 Flash.
