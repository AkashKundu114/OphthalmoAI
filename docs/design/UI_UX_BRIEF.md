# UI & UX Design Brief: OphthalmoAI

## 1. Design Direction & Persona Strategy
OphthalmoAI bridges consumer-facing accessibility with academic rigor:
1. **Public View**: Clear, non-intimidating visual language, high-contrast typography, actionable patient guidance, and empathetic phrasing.
2. **Academic / Clinical View**: High data density, empirical statistical metrics, confidence calibration parameters ($T$, ECE), multi-class probability distributions, and citation tools.

---

## 2. Design System Tokens

### Brand & Interface Colors
- **Primary Accent**: Cyan-600 (`#0891b2`) / Sky-500 (`#0ea5e9`)
- **Background**: Slate-900 (`#0f172a`) to Slate-950 (`#020617`) dark theme with Slate-50 light elements
- **Surface Containers**: Slate-800 (`#1e293b`) with 1px border Slate-700 (`#334155`)
- **Typography**: Clean system sans-serif (`Inter`, system-ui, -apple-system)

### Clinical Severity & Urgency Palette
- **Normal / Healthy**: Emerald-500 (`#10b981`) / Emerald-950 background
- **Elective / Low Urgency**: Sky-500 (`#0ea5e9`) / Sky-950 background
- **Urgent / Sight-Threatening**: Amber-500 (`#f59e0b`) / Amber-950 background
- **Emergency**: Rose-500 (`#f43f5e`) / Rose-950 background
